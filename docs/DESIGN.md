# RIL gallery direction

Source: the supplied RIL Media kit and programme-folder screenshot.

Use the supplied horizontal black logo, Open Sans, white, charcoal #212120, and primary blue #177AE5. White provides the calm photographic canvas specified by the brand; blue highlights the main title and focus states. Use the existing photographs without invented event dates or programme expansions.

An editorial opening introduces the people, followed by four folder-like album links matching the reference and separate photographic sections. Counts come from included files. Asymmetric photo widths keep the group context prominent. Small corner radii preserve the folder reference without turning photos into cards. Wide section spacing distinguishes programmes; compact intra-album spacing groups related images. Native modal viewing supports detailed inspection with keyboard controls. Hover image scaling indicates that a photograph can be opened.

The Next.js refinement preserves this photographic world. Decorative eyebrows and sequence numbers are removed; actual photograph counts identify each folder. A shorter opening brings the photo into the first viewport. Display tracking is limited to -0.04em. Blue selection, focus, and the current album share one meaning: orientation. Crisp SVG controls replace Unicode icons. Thumbnail navigation belongs inside the viewer, which protects focus while inspecting photographs. A single 280ms viewer entrance confirms the transition; reduced-motion users receive no animation. The page is rendered at build time, with React only for interactive album and viewer behavior.

ENERGY 3 / RHYTHM 2 / MOTION 1. The blue two-line title provides energy. Large opening photography and varied album layouts establish rhythm. Motion is limited to hover and scrolling, respecting reduced motion.
